Backup Suite 1.1.3: an update no longer fails when a release comes out after the check.

- The Updates window checks GitHub again right before it starts an update, so it
  asks for the current latest release.
- If a newer release is published between the check and the install, the updater
  installs that one (noted in the log) instead of stopping with "The latest release
  is X, not Y". Only the latest release is ever installed.
