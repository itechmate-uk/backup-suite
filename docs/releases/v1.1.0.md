Backup Suite 1.1.0: updates from the GUI, and a GUI that needs no sudo.

## New

- **Self-update.** Admin → Updates (and an **Update available** button in the top
  bar) updates Backup Suite and the GUI from this project's GitHub releases, like
  agentw and agentw-gui. Only the latest published release can be installed; its
  archive must match its published SHA-256 before anything runs.
  - Backup Suite is updated in the background by its own installer (as root in a
    system install, through the control broker): a running backup is waited for or
    stopped, the tests run first, and a failure keeps the previous version.
  - Your GUI updates itself as your login and restarts; if it does not start, the
    previous one is put back.
  - The GUI checks for new releases every 6 hours (Settings → General → Updates).
- **The GUI without sudo.** `./install.sh --gui-only` installs or updates only your
  own GUI. The GUI never runs as root.
- **System-wide GUI (optional).** `sudo ./install.sh --gui-system`: one GUI service
  for the whole server, run by the unprivileged account `backup-suite-gui`, for the
  members of the group `backup-suite-gui`.

## Upgrading from 1.0.x

1.0.x has no updater, so update once by hand; after that, use Admin → Updates.

```bash
curl -fLO https://github.com/itechmate-uk/backup-suite/releases/download/v1.1.0/backup-suite-1.1.0.tar.gz
curl -fLO https://github.com/itechmate-uk/backup-suite/releases/download/v1.1.0/backup-suite-1.1.0.tar.gz.sha256
sha256sum -c backup-suite-1.1.0.tar.gz.sha256
tar -xzf backup-suite-1.1.0.tar.gz && cd backup-suite-1.1.0
sudo ./install.sh        # or ./install.sh for a user install
```
