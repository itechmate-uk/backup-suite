Backup Suite 1.1.5: an update asks before it waits for a running backup.

- When a backup is running, updating Backup Suite asks first: **Stop the backup and
  update now** (recommended) or **Wait for it, then update**. Stopping does no harm:
  what the backup already copied stays backed up, nothing on the destination is
  removed, and the next backup run, shortly after the update, covers the rest.
- The same choice applies to the terminal update of an older Backup Suite.
- The "Stop a running backup instead of waiting" checkbox is gone; the dialog asks
  only when a backup is actually running.
