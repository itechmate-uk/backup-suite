Backup Suite 1.1.1: the Updates button, like agentw-gui's.

- The top-bar button always shows the update state: **Up to date**, or in amber
  **Update available**, or **Updating…**. It opens the Updates window (no longer an
  Admin tab), where **Update everything** updates Backup Suite first and then this
  GUI, and reloads the page on the new GUI. Each part can still be updated alone.
- Backup Suite 1.1 and later update from the GUI with no password: the root control
  service installs the verified release. A Backup Suite older than 1.1 shows the
  commands for its one manual update, with a Copy button.
- The documentation and the installer's help name the recommended setup:
  Backup Suite system-wide (root) with a GUI per admin login (no root); a shared
  system-wide GUI and a user-only install are options.
- `install.sh --gui-admin LOGIN --gui-only` also gives that login access to the
  control service, so its new GUI can reach Backup Suite.
- The updater's state folder defaults to Backup Suite's own (`/var/lib/backup-suite/updates`
  as root).

Update from 1.1.0 with the Updates button. From 1.0.x, see the
[1.1.0 notes](https://github.com/itechmate-uk/backup-suite/releases/tag/v1.1.0).
