Backup Suite 1.1.2: update an older Backup Suite from the GUI, in a terminal.

- A Backup Suite older than 1.1 has no update service, so its update now runs in a
  terminal inside the Updates window, like agentw-gui's operations: the command's
  output streams in, and sudo asks for your password there. Type it in the input
  box ("Hide what I type" is on by default) and press Send Input; the GUI passes it
  to the terminal as typed and keeps nothing. The update then runs in its own root
  unit (download, SHA-256 check, a running backup is waited for, tests, rollback on
  failure) and its log follows in the terminal. Closing the window does not stop it.
- **Update everything** uses that terminal for such a Backup Suite, then updates
  this GUI and reloads the page.
- Backup Suite 1.1 and later keep updating without a password, through the root
  control service.
